Client User Guidelines
  • Each client user must be associated with a client
  • Use valid email addresses for all client users
  • Assign appropriate roles based on the user's relationship to the client
  • Set access permissions according to what the user needs to see
  • Grant case access only to relevant cases
  • Send invitations to activate user accounts
  • Review all details before submitting
Client User Roles

The main point of contact for the client. Has full access to all client information and can make decisions on behalf of the client.

An additional contact person for the client. Has access to most client information but may have limited decision-making authority.

A contact person for a specific case. Has access only to information related to that case and cannot view other cases or general client information.

A contact person responsible for financial matters. Has access to invoices, payment information, and financial documents.

A contact person with a specific role not covered by other categories. Access permissions are customized based on the user's needs.
Client User Statuses

User account is active and the user can access the client portal.

User has been invited but has not yet activated their account.

User account is inactive and the user cannot access the client portal.

User account has been suspended due to policy violations or other issues.
