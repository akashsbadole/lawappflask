API Usage
API Documentation

All API requests must include an API key in the Authorization header:

Authorization: Bearer YOUR_API_KEY

You can generate API keys from the API Keys section above.

Endpoint Method Description
/api/clients GET Retrieve a list of clients
/api/clients/{id} GET Retrieve a specific client
/api/cases GET Retrieve a list of cases
/api/cases/{id} GET Retrieve a specific case
/api/invoices GET Retrieve a list of invoices
/api/invoices/{id} GET Retrieve a specific invoice

The API is rate limited to 1000 requests per hour per API key. When you exceed this limit, you will receive a 429 Too Many Requests response.

The following headers are included in API responses to help you track your usage:

  • X-RateLimit-Limit: The maximum number of requests allowed in the current time window
  • X-RateLimit-Remaining: The number of requests remaining in the current time window
  • X-RateLimit-Reset: The time when the current rate limit window resets (UTC timestamp)
