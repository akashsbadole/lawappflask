Template Creation Tips
Variable Placeholders

Use the following format for variables in your templates:

  • {{ '{client_name}' }} - Client's full name
  • {{ '{case_number}' }} - Case reference number
  • {{ '{current_date}' }} - Current date
  • {{ '{firm_name}' }} - Your firm name
  • {{ '{lawyer_name}' }} - Assigned lawyer name
Best Practices
  • Use descriptive variable names
  • Include comments for complex templates
  • Test templates with sample data
  • Keep templates organized by category
  • Regularly update outdated templates
